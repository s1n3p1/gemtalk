# Related projects

Research date: 2026-10-03. This comparison identifies overlapping capabilities; it is not a legal clearance or an exhaustive search.

| Project | Overlap | GemTalk's scope |
| --- | --- | --- |
| [SillyTavern](https://github.com/SillyTavern/SillyTavern) · [group chat documentation](https://docs.sillytavern.app/usage/core-concepts/groupchats/) | Custom characters, group conversations, automatic conversation | A small spectator app driven by separately authenticated Antigravity CLI conversations. |
| [AutoGen](https://github.com/microsoft/autogen) | Conversation between autonomous agents, human participation | A ready-to-run web app for casual conversation rather than an agent programming framework. |
| [ChatDev](https://github.com/OpenBMB/ChatDev) | Multi-agent orchestration and visible interaction | Casual character conversation rather than collaborative task and software-development orchestration. |

The general concept of several AI characters talking already exists. GemTalk's original implementation was committed before this comparison: `dd75ec8`. This release extends that implementation. It does not import these projects' source code, layouts, character cards, or artwork. The custom vector living room and characters remain project assets. Font licensing is recorded in [NOTICE](../NOTICE.md).

The name also overlaps with the existing [GemTalk organization](https://github.com/GemTalk), which publishes GemStone/Smalltalk-related software such as [Jasper](https://github.com/GemTalk/Jasper). That is a separate product and organization. This research does not establish trademark availability.
